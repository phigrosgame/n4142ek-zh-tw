# 女神異世界轉生想成為什麼-我勇者的肋骨輕小說

> 原文：[『女神「異世界転生何になりたいですか」俺「勇者の肋骨で」』](https://ncode.syosetu.com/n4142ek/)　作者：安泰

## 關於本作

安泰氏所撰的輕小說風短篇喜劇。特色是「**純對話推進、全無動作描寫**」，每一話都由網友投稿的「想轉生成什麼」為題，產生一段搞笑轉生短劇。本書已由寶島社集結出版。

繁體中文譯本採**章節獨立 .txt** 存放。每一話開頭會標註原文標題、原文網址、作者後記；文末附【注釋與梗解析】及【網友評論】。

翻譯原則：
- 保留日文人名 / 專有名詞用片假名原文（ex. アルマジロ、田中）
- 對話與旁白維持輕小說廢笑風格，台詞混搭白話
- 雙關 / 致敬伏筆一律標注於【注釋】段
- 風格為範本：原文↔譯文相互襯托，便於讀者對照
