## 零、AI 翻譯邏輯指南 (God Mode Manual)

如果你是接手的 AI，請務必內化以下翻譯哲學，否則會被使用者噴爆：

### 1. 結構優先順序
每一話的輸出結構必須嚴格遵守：
1.  **【文章完整中文翻譯】**：正文對話。
2.  **【網友評論摘錄】**：去 [官方留言區](https://novelcom.syosetu.com/impression/list/ncode/1144028/) 抓取真實留言，篩選有梗的。
3.  **【雙關語與搞笑梗解析】**：拆解文中的諧音、動漫梗、文化梗。

### 2. 「暴力括號補充法」
不要試圖在註釋裡解釋一切，要在正文中**當場解決**。
- 只要遇到諧音雙關、冷門文化、特殊語氣，必須在譯文後緊跟 `（原文，解釋）`。
- **範例**：`『如果你不去打魔王，你這輩子就只能當個不中用的傻茄子（おたんこナス，日本經典罵人蠢蛋的俗語）』`
- **廣告梗要求**：如果是廣告詞致敬，必須附上**中文對應廣告語**。

### 3. 通順度與代名詞
- **通順度 > 靈魂**：讀起來要像活人說的話，不要有翻譯腔。
- **您 vs 你**：嚴格判斷日文語境。女神對主角（或主角對神）在諷刺或丁寧語時用「您」，一般互噴用「你」。

### 4. 拒絕廢話註釋
- **禁止**介紹「勇者、魔王、異世界」等常識。
- **必須**介紹「田中、紅鮭魚、六角恐龍」等本作特有循環梗的演變。
